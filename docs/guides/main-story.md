## 01 这个任务做什么

主线卡带里，高难度关卡通关后会解锁「快速探索」：进关卡后右上角出现「进行快速探索」，
点开是一张任务列表，游戏可以自动推进节点、自动接手战斗。这个任务就是替你在正确的时候
点三个按钮，把整条流程循环跑下去。

它**不负责**进关卡、切难度、领奖励。运行前请自己在游戏里做完这些，把角色停在目标关卡里。

## 02 第一次怎么运行

1. 在游戏里进入目标关卡（困难或极难），确认右上角已经出现「进行快速探索」。
2. 打开「主线快速探索」的设置，把「主线关卡标题校验」填成列表页标题的一部分，
   例如 `血骑士-极难`。留空则不校验。
3. 设置「主线战斗次数上限」和「主线时间上限分钟」，0 表示不限。
4. 回到游戏，点击任务旁的「开始」。

任务会自己判断当前停在哪个界面，所以从「关卡内」或从「任务列表」开始都可以。

## 03 它是怎么判断的

每一步都读当前画面，不按固定顺序点击：

| 看到的界面 | 判定依据 | 动作 |
| --- | --- | --- |
| 关卡内 | 右上角读到「进行快速探索」 | 点开列表 |
| 任务列表 | 右下角按钮读到「自动进行」 | 点它，让游戏自动推进 |
| 任务列表 | 右下角按钮读到「战斗」 | 点它，进入战斗 |
| 战斗结算 | 右下角读到「离开」 | 点它，回到关卡内继续下一轮 |
| 其他 | 都读不到 | 等待，超时才停止 |

节点顺序不固定，中间还会夹杂剧情、掉落等界面，所以**认不出来时只等待、不乱点**。
战斗中认不出界面属于正常，用「主线战斗等待秒数」兜底。

## 04 停下来的时候看什么

- 状态面板里的「主线当前界面」会显示当前判定和四块 ROI 的原始文字，方便对照。
- 非正常停止会把画面存到 `probe_outputs/main_story_stuck.png`（或 `main_story_abort.png`），
  停止原因写在「主线停止原因」。
- 「主线战斗次数」「主线自动进行次数」「主线完成轮次」是本次运行的计数。

## 05 常见问题

**为什么一开始就停了，提示按钮文字未知？**

列表页右下角既不是「自动进行」也不是「战斗」，通常是这一关已经没有可推进的节点，
或者游戏改版换了按钮文案。先手动看一眼那个按钮写的是什么，再决定要不要继续。

**为什么点了没反应，反复停在同一个界面？**

先确认游戏窗口没有被其它窗口挡住、分辨率比例是 16:9。若确实点不动，多半是界面位置
变了，需要重新标定 ROI。

**会不会误点到别的功能？**

不会。四个点击位置都是固定的按钮区域，并且每次点击前都要先在该区域读到对应文字；
读不到就不点。
